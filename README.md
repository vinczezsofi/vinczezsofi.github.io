# Vincze Zsófia – statikus portfólió weboldal

**Nyelv:** magyar  
**Technika:** HTML + CSS (statikus), Calendly és Formspree beágyazás  
**Hosztolás:** GitHub Pages *vagy* Netlify (ingyenes)

## Gyors indítás
1. Cseréld le a `index.html` fájlban az alábbi helyeket:
   - `https://példa.hu/` → a saját domain vagy aldomain.
   - E‑mail link: `hello@pelda.hu` → saját címed.
   - Calendly: `https://calendly.com/YOUR_LINK` → a saját időpontfoglaló linked.
   - Formspree: `https://formspree.io/f/SAJAT_FORM_ID` → a saját űrlapvégpontod.
2. (Opcionális) Cseréld le a képeket saját fotókra.
3. Töltsd fel a mappát GitHub Pages-re *vagy* húzd be Netlifyra.

## GitHub Pages (ingyen)
- Létrehozol egy új publikus repót `username.github.io` néven → Fájlok feltöltése → Settings → Pages → forrás: `main` ág → Pár perc és él a site.  
  Részletes leírás: GitHub Pages Quickstart. 

## Netlify (ingyen)
- Bejelentkezés → **Add new site** → **Deploy manually** → húzd be a mappát vagy a ZIP fájlt → azonnal kapsz egy ideiglenes URL-t; később egyedi domaint is állíthatsz.

## Űrlap bekötés (Formspree)
- Hozz létre egy formot a Formspree-ben, majd másold be az `action` URL-t a `index.html`-ben.  
- Nézd meg az aktuális csomaglimitjeiket és a rendszerlimiteket a Formspree súgójában.

## Calendly beágyazás
- A `#contact` szekcióban cseréld `YOUR_LINK` részre a saját oldalad.  
- Ha görgetősáv jelenik meg, növeld a `height` értéket vagy használd a `data-resize="true"` attribútumot.

## SEO
- Cím és leírás: szerkeszd a `<title>` és `<meta name="description">` elemeket.  
- Adj saját Open Graph képet (1200×630 px).
